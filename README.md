## 🚀 Featured Projects

### [FarmLink](https://github.com/ysheriff786/farmlink) — Farmer-to-Customer Marketplace 🌾

An online marketplace connecting local farmers directly with customers — farmers list fresh produce, customers order at fair prices, no middlemen.

- **Stack:** Python (Flask) · SQLite · vanilla JS/CSS · scikit-learn
- 6 roles (farmer, FPO, customer, bulk buyer, logistics, admin), stock-aware cart &amp; checkout, Razorpay payment verification (HMAC), delivery OTP, reviews, farmer dashboards with earnings charts
- Demand-forecast service plus smoke, security, and feature test suites
- Deployed live on Render

**What I learned:** building a full web app end-to-end — models, auth, roles, payments, testing, and deployment.

🔗 [Repository](https://github.com/ysheriff786/farmlink) · 🌐 [Live demo](https://farmlink-kc05.onrender.com) *(free tier — may take a minute to wake up)*

### [PlantSense](https://github.com/ysheriff786/plantsense) — Smart Agriculture Assistant 🌱

A smart-plant monitoring platform that ingests sensor telemetry and runs real ML diagnostics — entirely in the browser.

- **Stack:** React + TypeScript · Vite · Tailwind CSS · Zustand · ONNX Runtime · Three.js
- On-device ML (WebNN → WebGPU → WASM) for plant disease &amp; pest detection — real inference, no mocked results
- Sensor feeds from MQTT gateway or USB Serial (ESP32/Arduino), or a built-in simulator
- Offline-first, installable **PWA** that queues scans and syncs later
- Built for **Smart India Hackathon 2026** (Qualcomm-sponsored problem statement)

**What I learned:** modern frontend tooling, in-browser ML, PWA/offline architecture, and working with real hardware data sources.

🔗 [Repository](https://github.com/ysheriff786/plantsense)
