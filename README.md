## 🚀 Featured Projects

### [PlantSense](https://github.com/ysheriff786/plantsense) — Smart Agriculture Assistant 🌱

A smart-plant monitoring platform that ingests sensor telemetry and runs **real ML diagnostics entirely in the browser**.

- **Stack:** React 19 + TypeScript · Vite · Tailwind CSS · Zustand · ONNX Runtime · Three.js
- On-device ML (WebNN → WebGPU → WASM) for plant disease & pest detection — real inference, no mocked results
- Sensor feeds from MQTT gateway or USB Serial (ESP32/Arduino), or a built-in simulator
- Offline-first, installable **PWA** that queues scans and syncs later
- Built for **Smart India Hackathon 2026** (Qualcomm-sponsored problem statement)
- Deployed on GitHub Pages

**What I learned:** modern frontend tooling, in-browser ML, PWA/offline architecture, and working with real hardware data sources.

🔗 [Repository](https://github.com/ysheriff786/plantsense)

### [TechAlpha](https://github.com/ysheriff786/Techalpha) — Smart Rural Healthcare Platform 🏥

Full-stack healthcare platform exploring appointment management, live queues, emergency workflows, symptom checking, and administrative analytics. The advanced full-stack version is currently in active development locally; the public repository currently contains the earlier frontend version.

- **Stack (advanced version):** Node.js · Express · MongoDB (Mongoose) · JWT/bcrypt auth · helmet · rate limiting
- Role-based access (patient / doctor / admin), live queue tokens, appointments & reminders, emergency requests
- Rules-based symptom checker, Chart.js analytics dashboard, bilingual (EN/TA) support

🔗 [Repository](https://github.com/ysheriff786/Techalpha)
